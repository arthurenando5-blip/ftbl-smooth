# 📱 FTBL SMOOTH - Guia Rápido para Samsung Galaxy A20S

## 🎯 OPÇÃO MAIS FÁCIL: Deploy Online (Sem PC!)

Vou fazer o deploy para você rodar 100% online.

---

## ⚡ PASSO 1: Criar Conta (1 minuto)

Vá para: **https://render.com**

- Clique em "Sign Up"
- Use email do Gmail
- Confirme email

---

## 📂 PASSO 2: Conectar GitHub

1. No Render, clique em "Connect GitHub"
2. Autorize o acesso
3. Selecione: `arthurenando5-blip/ftbl-smooth`

---

## 🚀 PASSO 3: Deploy (2 minutos)

1. No Render, clique em "New +"
2. Selecione "Web Service"
3. Escolha: `ftbl-smooth`
4. Nome: `ftbl-smooth`
5. Build command: `npm install`
6. Start command: `npm start`
7. Clique em "Create Web Service"

**Aguarde 3-5 minutos...**

Quando ficar verde ✅, você terá um link tipo:
```
https://ftbl-smooth-xxxxx.onrender.com
```

---

## 📱 PASSO 4: Acessar no Celular

1. Abra o navegador do Samsung (Chrome)
2. Cole o link do Render
3. **PRONTO!** 🔥

## 🆘 Problema?

**Não vê o deploy ficar verde?**
- Aguarde mais 5 minutos
- Atualize a página (F5)

**Erro ao processar vídeo?**
- FFmpeg online tem limitações
- Vídeos pequenos funcionam melhor (< 50MB)

**Quer rodar localmente depois?**
- Baixe Node.js no PC
- `git clone` + `npm install` + `npm start`
